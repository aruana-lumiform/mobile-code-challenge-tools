Mobile Code Challenge — hosted assets

Static assets for the Android code challenge: the document JSON the app fetches, plus the images it references. Served over HTTPS by GitHub Pages.

Endpoint

https://aruana-lumiform.github.io/mobile-code-challenge-tools/code-challenge/challenge.json

Served as application/json, with ETag and Cache-Control: max-age=600.

Try it

curl -i https://aruana-lumiform.github.io/mobile-code-challenge-tools/code-challenge/challenge.json

Images

Document structure

  • page — top level, has a title and items
  • section — has a title and items, and may nest
  • text / question — leaf, has content
  • image — leaf, has src and title
